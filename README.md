# 🐦 Bird Journal App

A simple full-stack web application for posting and sharing bird sightings with images.  
Built as a learning project to practice React and backend development.

---

## 🌍 Project Idea

This app allows:
- 🧑 Admin user (girlfriend) to create posts with bird photos
- 🖼️ Upload and display bird images
- 👀 Visitors to browse posts
- 💬 (future) Comments without login
- 🔐 (future) Authentication system

---

## ⚙️ Tech Stack

### Frontend
- React
- Vite / Create React App
- JavaScript
- Basic CSS

### Backend
- Node.js
- Express.js
- CORS
- Multer (for image uploads - future step)

### Database (future)
- SQLite / PostgreSQL
